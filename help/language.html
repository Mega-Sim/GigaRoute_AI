Time duration

Purpose
Time represents an elapsed simulation duration, stored as signed integer microseconds.
Syntax
<number> sec | <number> min | <number> hour
Example
begin model.init event
    set pickupTime = 10 sec
    set cycleTime = 2 hour + 30 min
    set halfTime = cycleTime / 2
    print cycleTime to log
end
Notes
Time is different from Integer/Real. Time + Time and Time - Time yield Time; Time multiplied or divided by a number yields Time; Time / Time yields a ratio. Comparisons require two Time values. Logs render durations in seconds. Unit aliases sec/secs/second(s), min/mins/minute(s), hr/hrs/hour(s), day(s) are accepted. Plain numbers remain Integer/Real. Ordinary user-authored wait statements remain restricted by the current GRS syntax policy.
