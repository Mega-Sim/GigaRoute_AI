Humanoid walk events (two-file global init)

Purpose
Run starts OHT 10, AMR 3 and Humanoid 3 and drives Humanoid 1 and 2 back and forth through physical floor Stations.
Syntax
model_init.grs + humanoid_logic.grs
Example
begin Humanoid walk resume event
    wait for 0.5 sec
end
begin Humanoid walk start event
    print this humanoid, " walk start now" to log
end
begin Humanoid arrived at station event
    if (current station = humanoid_1)
        dispatch this humanoid to humanoid_2
    else if (current station = humanoid_2)
        dispatch this humanoid to humanoid_1
end
Notes
Opt-in requires two GRS files: model_init.grs with vi_OHT, vi_AMR, vi_Humanoid and OHT.init, AMR.init, Humanoid.init; and humanoid_logic.grs with walk resume/start/arrived at station events. All three Init callbacks must complete across all modules before any regular t=0 event or initial humanoid walk begins. A waiting/failed Init rejects Run before simulation time advances. In model_init.grs the authored spwan Humanoid(1 or 2) to humanoid_1 or humanoid_2 is accepted as compatibility syntax. These compile to native humanoid_create, humanoid_walk_to, humanoid.arrived and a suspended 0.5-second wait. Each physical arrival triggers the next leg, without every-event polling. Humanoid 3 remains idle until explicitly dispatched; Job flows removed from this project are not auto restored. Existing auto-bound and explicitly declared module behavior is unchanged.
