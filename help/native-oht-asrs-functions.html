OHT_System_Initialize()

Purpose
Initializes the native OHT model session.
Syntax
call OHT_System_Initialize()
Notes
Uses the existing OHT engine.

ASRS_Stocker_Initialize()

Purpose
Initializes stocker inventory and cycle state.
Syntax
call ASRS_Stocker_Initialize()
Notes
Call before shelf seeding and first outbound.

ASRS_External_Handoff_Mode()

Purpose
Hands outbound FOUPs to downstream modules.
Syntax
call ASRS_External_Handoff_Mode()
Notes
Set before the first outbound cycle.

Purpose

Syntax

Notes

ASRS_Add_In_Lane(station, slot_count[, transfer_height_mm])

Purpose
Adds an inbound Port Lane: OHT sets down at the Station, then an N-slot conveyor feeds the Crane.
Syntax
call ASRS_Add_In_Lane(station, slot_count[, transfer_height_mm])
Notes
Call after asrs_stocker_initialize and before asrs_request_first_outbound. Masks one Shelf cell as slot 0. Returns the lane index.

ASRS_Add_Out_Lane(station, slot_count[, transfer_height_mm])

Purpose
Adds an outbound Port Lane: the Crane deposits ahead into an N-slot conveyor and OHT picks up at the Station.
Syntax
call ASRS_Add_Out_Lane(station, slot_count[, transfer_height_mm])
Notes
Same call order as asrs_add_in_lane. Returns the lane index.

ASRS_Add_Bidirectional_Lane(station, slot_count, direction[, transfer_height_mm])

Purpose
Adds a Port Lane whose direction ("in" or "out") can change while it is empty.
Syntax
call ASRS_Add_Bidirectional_Lane(station, slot_count, direction[, transfer_height_mm])
Notes
Use asrs_set_lane_direction to switch. Returns the lane index.

ASRS_Set_Lane_Direction(lane, direction)

Purpose
Switches a bidirectional Port Lane to "in" or "out".
Syntax
call ASRS_Set_Lane_Direction(lane, direction)
Notes
Returns false if the lane is not bidirectional or still holds FOUPs.

ASRS_Set_Lane_Slot_Move_Seconds(lane, seconds)

Syntax
call ASRS_Set_Lane_Slot_Move_Seconds(lane, seconds)

Call before asrs_request_first_outbound.

Notes

ASRS_Set_Rack(bays, levels, cell_width_mm, cell_height_mm, cell_depth_mm)

Purpose
Sets the Rack size (default 8 x 6, 650 x 500 x 700 mm). Replaces the empty Stocker, so no Lane or seeded FOUP may exist yet.
Syntax
call ASRS_Set_Rack(bays, levels, cell_width_mm, cell_height_mm, cell_depth_mm)
Notes
Call right after asrs_stocker_initialize. Example: asrs_set_rack(10, 6, 450, 400, 1000) is the default Place STK.

ASRS_Add_In_Port(station, bay, level [, depth_mm])

Purpose
Uses one front-column Shelf cell as an In Port (a one-slot Lane): the OHT sets down straight into that cell and the Crane stores from it.
Syntax
call ASRS_Add_In_Port(station, bay, level [, depth_mm])
Notes
Call after asrs_set_rack and before asrs_request_first_outbound. The OHT transfer height is the cell's FOUP centre height. Returns the lane index.

ASRS_Add_Out_Port(station, bay, level [, depth_mm])

Purpose
Uses one front-column Shelf cell as an Out Port (a one-slot Lane): the Crane retrieves into that cell and the OHT picks up from it.
Syntax
call ASRS_Add_Out_Port(station, bay, level [, depth_mm])
Notes
Same call order as asrs_add_in_port. Returns the lane index.

ASRS_Set_Out_Buffer(cell_id)

Purpose
Adds a Side Buffer Cell as a destination for FOUPs leaving an Out Lane; each FOUP reserves the first free candidate and the Cell becomes occupied when the OHT Setdown completes.
Syntax
call ASRS_Set_Out_Buffer(cell_id)
Notes
Call after asrs_stocker_initialize and before asrs_request_first_outbound, once per Cell. Lane mode only. A Load set down on an In Lane Station by any other OHT job is accepted by that Lane automatically.
