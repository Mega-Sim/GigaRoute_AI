Core Actions

4 GRS reference entries.

print to log

Purpose
Writes text to the Studio message log.
Syntax
print <value>, <value>, ... to log
Example
print "vehicle ", vehicle.id, " arrived" to log
Notes
Arguments are rendered in order. print ... to message was removed; use to log.
Related
Model Logic log

set

Purpose
Assigns a variable or a writable attribute.
Syntax
set <name> = <value>
<name> = <value>
Example
set count = 0
set Vehicle.my_counter = 3
Notes
Custom attributes on Vehicle are script-side values and never overwrite physical Vehicle state.
Related
inc, dec, attributes

inc

Purpose
Increments a numeric variable or attribute.
Syntax
inc <name> by <amount>
Example
inc count by 1
Notes
Unwritten numeric values begin at 0.
Related
set, dec

dec

Purpose
Decrements a numeric variable or attribute.
Syntax
dec <name> by <amount>
Example
dec count by 1
Notes
Unwritten numeric values begin at 0.
Related
set, inc
