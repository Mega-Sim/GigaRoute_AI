Reference for GRS (GigaRoute Script), the script language used for Model Logic in GigaRoute Simulation Studio. 344 entries are generated from the Help window of the product.

Start here

A GRS program is a set of events. An event such as model.init runs when something happens in the simulation (here: when a run starts), and its body is a list of statements. This is the smallest complete program:

event model.init {
    print("hello");
}

Read Language basics next for blocks, variables, conditions, loops and the compile errors you will meet. Then look up any event, action, function or attribute in the sections below.

How to read an entry
