Syntax
travel(...)  // removed
move_into(...)  // removed

Not Implemented

catalog-only actions

Purpose
These words may exist in parser/action-catalog infrastructure, but the current product EngineScriptHost does not provide executable Simulation Studio semantics for them as statements.
Syntax
terminate / remove / add / delete
open / read / write / close
schedule / choose (AutoMod statement form)
Example
// Use the implemented function forms instead:
choose(list, "min", "released_us");
schedule_in("my.event", 5);
terminate_load(load);
file_read_lines("data.txt");
Notes
Issue #30: the function forms choose(list [, mode, ...]), schedule_in(event, seconds) and schedule_at(event, seconds) ARE implemented (OHT) and listed in the callable index. Only the AutoMod-style statement keywords above remain parser-recognized without runtime meaning. Help must follow actual runtime support, not parser recognition alone.
Related
choose, schedule_in, schedule_at, terminate_load, file_read_lines, Action Catalog
