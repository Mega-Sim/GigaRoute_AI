vehicle.id [OHT, AMR]

Purpose
Returns the dense runtime Vehicle/Robot ID.
Syntax
vehicle.id
Example
print(vehicle.id);
Notes
Type: Number. Access: read-only. Modules: OHT, AMR. Physical runtime identity; not a user-defined attribute.
Related
