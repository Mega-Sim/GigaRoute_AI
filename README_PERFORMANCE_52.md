# Issue #52 — 8GB 사무용 노트북 Simulation Engine 성능 체감 강화

2026-09-16 기준 최신 `main`에서 기존 Simulation Engine 실측값을 유지하면서, 8GB RAM 사무용 노트북에서의 성능이 즉시 이해되도록 공개 성능 UI를 강화했습니다.

## 기준 실측값

- Vehicle: 1,100대
- 입력 물동량: 18,000 moves/h
- 시뮬레이션 시간: 3,600초
- 실제 실행시간: 166.981초
- Realtime Factor: 21.559×
- 완료 Job: 17,018건
- 측정 환경: Intel Core i5-1130G7 / RAM 8GB / integrated GPU / Windows x64

## 공개 표시 규칙

홈페이지 공개 성능 수치는 사용자 요청에 따라 소수점 한 자리로 통일합니다.

- 21.559× → `21.6×`
- 1,100대 → `1,100.0대`
- 18,000 moves/h → `18,000.0 moves/h`
- 17,018 jobs/h → `17,018.0 jobs/h`
- 166.981초 → `167.0초`
- 8.00GB / 7.70GB → `8.0GB / 7.7GB`

CPU 세대명, 제품명처럼 성능 측정 수치가 아닌 식별용 숫자는 임의로 소수점 표기하지 않습니다.

## 체감형 파생 지표

실측 결과를 이해하기 쉽게 다음 값을 추가 표시합니다.

- `21.6초`: 실제 1.0초 동안 진행되는 시뮬레이션 시간
- `약 101.9 Job/s`: 실제 실행시간 기준 평균 완료 Job
- `2.8분`: 1.0시간 시뮬레이션 완료 시간

`101.9 Job/s`는 완료 Job과 실제 실행시간에서 계산한 파생 지표이며 엔진 내부 이벤트 처리량(events/s)을 의미하지 않습니다. 따라서 홈페이지에서 이를 `events/s`로 표현하지 않습니다.

## 표현 정책

- 근거 없는 `현 상용 시뮬레이터에서는 불가능` 등의 경쟁 제품 단정 문구는 사용하지 않습니다.
- 대신 `8.0GB RAM 사무용 노트북`, `1,100.0대`, `21.6×`, `101.9 Job/s`, `2.8분`을 시각적으로 강조합니다.
- 기존 성능 스크린샷, 측정 환경, 제품/Consulting/다운로드 UI는 유지합니다.
- 이미지 자산은 변경하지 않았습니다.
- 한국어, 영어, 중국어(간체), 스페인어, 일본어 공통 `display-fixes.js` 경로에서 동일 구조로 반영합니다.

- `index-en.html`
- `index-zh.html`
- `index-es.html`
- `index-ja.html`

따라서 네 외국어 페이지에서도 8.0GB 사무용 노트북 성능 강조, 21.6×, 1,100.0대, 18,000.0 moves/h, 17,018.0 jobs/h, 167.0초, 101.9 Job/s, 2.8분 및 소수점 한 자리 공개 표기 규칙이 동일한 공통 코드로 적용됩니다.

## Issue #54 — 헤드라인 2줄 고정 및 중복 성능 블록 제거

사용자 화면에서 성능 제목이 좁은 2열 레이아웃 때문에 여러 줄로 잘게 분리되고, 상단 체감형 성능 카드 아래에 기존 성능 수치 3개와 측정 환경 블록이 다시 노출되어 내용이 중복되는 문제를 정리했습니다.

- 한국어 헤드라인을 정확히 다음 2줄로 표시합니다.
  - `8.0GB RAM 사무용 노트북 하나로`
  - `1,100대 AMHS를 21.6배속 시뮬레이션.`
- 제목 오른쪽의 기존 장문 설명(`1,100대 Vehicle ...`)은 제거합니다.
- 상단 체감형 카드 `21.6초 / 약 101.9 Job/s / 2.8분`은 유지합니다.
- 하단 기존 `21.6× / 1,100.0 / 17,018.0/h` 3개 카드와 `측정 환경` 블록은 제거합니다.
- 영어·중국어(간체)·스페인어·일본어도 동일한 2줄 헤드라인 + 단일 체감 성능 블록 구조로 맞춥니다.
- 데스크톱에서는 각 제목 줄을 고정하고, 좁은 화면에서는 overflow 방지를 위해 언어별 줄 내부 줄바꿈을 허용합니다.
- 기존 제품, Consulting, Research, 다운로드, Contact UI는 수정하지 않습니다.
